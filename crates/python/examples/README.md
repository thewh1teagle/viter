# Python examples

Standalone [uv](https://docs.astral.sh/uv/) scripts: `uv run <file> ...` installs `viter` from PyPI and runs it.

| file | shows |
|---|---|
| [align_numpy.py](align_numpy.py) | load a model once, align audio already in memory |
| [align_many.py](align_many.py) | batch alignment with per-speaker adaptation, TextGrids out |

Reference: [docs/PYTHON.md](../../../docs/PYTHON.md).
